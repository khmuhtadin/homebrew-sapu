# Homebrew tap for Sapu

[Sapu](https://github.com/khmuhtadin/sapu) is a Mac cleaner for the command
line that never deletes anything you can't undo.

```sh
brew install khmuhtadin/sapu/sapu
```

Update with `brew upgrade sapu`. The formula installs the universal binary from
the [GitHub release](https://github.com/khmuhtadin/sapu/releases) and checks its
SHA-256. 0.x releases are developer previews: not signed with an Apple
Developer ID or notarized. See
[verify your download](https://github.com/khmuhtadin/sapu/blob/main/docs/verify.md).

The formula is updated after each release; the steps are in
[docs/releasing.md](https://github.com/khmuhtadin/sapu/blob/main/docs/releasing.md).
